# Demo files

These files were captured from the Android `Pixel_7` emulator at `1080x2400`.

- `08-home-clean.png` shows the clean home screen.
- `09-validation-clean.png` shows the empty-input error.
- `10-about-clean.png` shows the username passed to the About screen.
- `two_screen_demo.mp4` shows the interaction flow in a short recording.

The demo uses the name `Professor Demo` so the screenshots are ready for a class handoff.
